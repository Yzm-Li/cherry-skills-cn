# 同人 OC 剧情合理化与随行同伴

## 适用

用户带着一个 OC（原创主角）和一部原作来，问“他/她进了这个故事，剧情该怎么改才合理”。也可能是：OC 替换某个原作角色、OC 和原作角色有旧关系、OC 带着前世记忆、OC 站在对立阵营。

目标不是“让 OC 爽”，是**让 OC 的存在改变剧情，同时不把原作的人物和因果链弄塌**。

如果用户要的是“让 OC 一直跟着原作主角、别掉线”，先读第八节“随行同伴模式”，再回头补变量和涟漪。

## 六条底线

1. **改处境，不改内核。** 原作角色的欲望、恐惧、底线、说话方式，不能为了给 OC 让路而改写。可以让他们因为新事实动摇，但不能突然换个人。
2. **不抢高光。** OC 可以参与关键场面，但要付出代价，并把另一处高光让出去。所有好事都归 OC，故事就死了。
3. **不复制原文。** 引用原作只做对照，不长段复述；改编写的是“变化”，不是“重贴一遍”。
4. **配对不跳过过程。** 好感要有理由，关系推进要有代价；拆原作 CP 要标 AU，不要假装 canon。
5. **标清楚私设。** OC、AU、拆 CP、改设定，在开头标明白，不冒充官方。
6. **同行不是附庸。** OC 要有自己的目标、关系和离开的能力；主角要有主动留他的理由。两个人都不是对方的配件，同行才好看。

## 先拿三样东西

- **OC 卡**：身份、能力与限制、关系、知道什么、想要什么、怕什么、代价。
- **Canon 基线**：原作、时间线、关键事件、人物内核、世界规则。
- **改编规模**：轻改、中改、重改。

缺哪个问哪个，最多问两个。用户没给规模，默认“中改里最小的改动”——只动一个关键节点，保留核心冲突。

如果用户只给了一句 OC 设定，先把它补成可用的变量，不要急着编剧情。用户没给原作时，不要凭记忆编 canon；先要作品名、版本/时间线，或让他贴关键设定。

## 一、把 OC 设定变成变量

不是所有设定都进剧情。只有**能改变选择**的设定才算变量。

| 设定 | 要问的问题 | 会改变什么 |
| --- | --- | --- |
| 身份/立场 | 他站在谁那边？谁知道他的身份？ | 谁能信任他、谁能用他 |
| 能力/资源 | 他能做到什么别人做不到的事？代价是什么？ | 冲突的解决方式、力量平衡 |
| 关系 | 他和哪个原作角色有旧关系？为什么原作没提？ | 动机、联盟、背叛 |
| 知识 | 他知道剧情/秘密吗？知道多少？会记错吗？ | 信息差、决策速度 |
| 目标 | 他想要什么？和主线目标冲突吗？ | 他为什么介入、何时退出 |
| 时间点 | 他什么时候进入？早一步/晚一步会怎样？ | 分叉点、能救/不能救谁 |
| 弱点 | 他怕什么、缺什么、会误判什么？ | 失败的可能、代价 |

每个变量至少回答三句：

1. 它让 OC 能做到什么别人做不到的事？
2. 代价/限制是什么？
3. 谁会发现，发现后会发生什么？

答不上来，这个设定就还只是人设标签，不是剧情变量。

## 二、Canon 基线

### 锚点事件

选 5–8 个“没有它们，这个故事就不是这个故事”的事件。每个锚点写：

- 事件：发生了什么
- 原因：为什么会发生（结构性压力，不是巧合）
- 参与者：谁在场，谁做了什么选择
- 后果：它把故事推到哪里
- 惯性：高/中/低（见第四节）

锚点不是“名场面清单”，是因果链的承重墙。

### 人物内核卡

给每个重要原作角色填：

| 项 | 内容 |
| --- | --- |
| 想要 | 表面目标 |
| 真正需要 | 故事结束时才明白的东西 |
| 怕 | 最怕失去什么 |
| 底线 | 什么事不做 |
| 说话方式 | 句长、称呼、口头禅、禁语 |
| 关系弧 | 和谁从什么关系走到什么关系 |

改编可以改变他们“遇到什么事”，不能改变他们“为什么是他”。

### 世界规则

- 能力上限、代价、冷却、暴露风险。
- 社会结构：谁有权力，谁被压迫，规则怎么执行。
- 禁忌与后果：打破规则会怎样。
- 时间与空间：赶路、通信、疗伤、调查各要多久。

### 区分 Canon / Fanon / 二创

- **Canon**：原作明确写出来的。
- **Fanon**：粉丝普遍接受但原作没写的。
- **二创**：这篇文自己的设定。

三者混用会出逻辑漏洞。不确定的标“待确认”，不要假装是原作。

原作很长时，先用 `longtext-index` 建索引，只读锚点和相关块，不要全文硬读。

## 三、找最早接触点

OC 第一次能影响 canon 的时间、地点、人物，就是分叉点。

- 接触点越早，改动越大；越晚，越容易轻改。
- 在此之前，canon 照常发生；在此之后，才开始分叉。
- 选“最小可改变节点”：能服务 OC 的目标，又不立刻推翻全局。
- 如果 OC 一开始就救下关键角色，要接受后面所有剧情重写；不想重写，就把接触点往后挪。

写清楚一句话：

> 分叉点：第 12 话，天台，A 被推下前 3 分钟，OC 第一次介入。

## 四、涟漪模型

### 三阶影响

- **一阶**：直接改变的事件。OC 救了人、挡了刀、提前泄密、拿走了关键物品。
- **二阶**：相关角色的反应、关系、阵营。被救的人怎么想？敌人怎么调整？谁开始怀疑 OC？
- **三阶**：组织、世界、终局。权力平衡变了，规则被触发，结局变量换了。

只写一阶，叫“改事件”；写到二阶，才叫“改剧情”；写到三阶，才叫“改世界”。

### 惯性

不是所有 canon 都会立刻改变。给每个锚点标惯性：

- **高**：结构性压力还在，事件会以另一种形式发生。反派仍要动手，制度仍要压人，只是时间、地点、方式变了。
- **中**：关键人物还在，但选择变了；事件可能推迟、缩小、转移。
- **低**：依赖巧合或单个人物的，容易被 OC 取消。

高惯性事件不能“因为 OC 来了就没发生”，要给替代形式。

### 信息传播

- 谁亲眼看见？谁只是听说？谁不信？谁故意压下去？
- 传播需要时间：一天、一周、一个月。
- 不要让人物知道他们不可能知道的事。
- OC 的秘密，知道的人越多，越容易变成把柄。

### 权力校准

OC 变强，对手也要升级，或者换一种打法。

- 如果 OC 能一招解决，冲突就不成立；给他限制、代价、误判。
- 如果 OC 带来新资源，既得利益者会反应：拉拢、监视、抢夺、污名化。
- 不要让反派降智来配合 OC。

### 时间成本

决策、赶路、疗伤、调查、传信都要时间。改编后的事件表要能回答：

- 这件事什么时候发生？
- 上一件事结束后，人物来得及赶到吗？
- 伤/损失恢复了吗？
- 信息传到该听的人耳朵里了吗？

## 五、合理化七问

任何一处改动，过一遍：

1. **动机**：他为什么现在做这件事？不做会怎样？
2. **能力**：他的能力/资源够吗？代价是什么？
3. **机会**：时间、地点、信息允许吗？
4. **反应**：原作角色按自己的性格会怎么反应？不会立刻接受、不会立刻爱上、不会立刻听话。
5. **代价**：他失去了什么？谁恨他？哪条路被堵死？
6. **传播**：这件事多久传到谁耳朵里？谁信，谁不信？
7. **主题**：这个改动让故事在问什么？只是爽，还是推进了主题？

七问里有两问答不上来，这个改动就不合理：要么补因果，要么砍掉。

## 六、改编规模

| 规模 | 动什么 | 保留什么 | 风险 |
| --- | --- | --- | --- |
| 轻改 | OC 是边缘参与者，补线、加关系、加代价 | 主线、结局、人物弧 | OC 像旁观者，容易被删 |
| 中改 | OC 改变一个关键节点 | 核心冲突、人物内核、主题 | 涟漪收不住，越写越偏 |
| 重改/AU | OC 的设定改写世界规则 | 只保留精神内核或人物 | 需要重建设定，必须标 AU |

默认中改的最小版本：只动一个节点，先写清楚它的一阶、二阶、三阶后果，再决定要不要继续扩大。

## 七、六种 OC 类型与补丁

| 类型 | 核心 | 必须补的漏洞 |
| --- | --- | --- |
| 插入型 | 世界里多了一个人 | 原作为什么没提？——不在场、化名、被忽略，别硬解释 |
| 替换型 | OC 取代某个原作角色的位置 | 被替换角色的功能谁承担？粉丝情感怎么安置？ |
| 关系型 | OC 与原作角色有旧关系 | 为什么原作没出现？——断联、隐瞒、时间差 |
| 信息型 | 穿越/重生/预知 | 为什么不直接解决？——记忆模糊、蝴蝶效应、说了更糟 |
| 能力型 | OC 带来新能力/技术/资源 | 为什么不横扫？——代价、冷却、暴露风险、规则限制 |
| 阵营型 | OC 站在对立面 | 怎么不脸谱化？——给对方合理诉求，让他也有代价 |

每种类型都要回答一句：**“为什么原作里没有这个人？”** 答不好，读者会一直出戏。

## 八、随行同伴模式

用户说“让 OC 跟着主角”“加入主角团”“一起上路”“别让 OC 掉线”时，用这一节。目标不是让 OC 黏在主角旁边，是**让两个人有理由同行、有东西可吵、分开也各自成立**。

### 1. 先写“同行契约”

OC 能长期留在主角身边，至少满足两条，其中一条必须是**主角主动**：

| 绑定 | 要写清楚 |
| --- | --- |
| 共同目标 | 两人短期或长期要去的方向重叠 |
| 互补 | OC 补主角的盲区，主角补 OC 的缺口，双方都有用 |
| 人情/责任 | 救过、欠过、答应过、被托付 |
| 外力 | 通缉、契约、任务、同住、同队，分开就有麻烦 |
| 情感 | 信任、好奇、愧疚、吸引，不一定是爱情 |
| 分开代价 | 分开会失去什么，且这个损失马上会发生 |

只有“OC 想跟”不够。必须写一句：**主角为什么允许他跟着？** 并且让主角做一次主动动作：邀请、默许、挽留、利用、监视。没有这个动作，同行就是硬凑。

### 2. 给 OC 一个功能位

在主角身边至少占两个，且不能全能：

- **镜子**：照出主角不愿承认的一面。
- **反衬**：同一个问题，OC 做不同选择，逼主角解释自己。
- **补位**：补主角缺的能力、视角或社会关系，但有代价。

只做打手、解说、啦啦队，就是挂件。

### 3. 目标三角

- **共同目标**：为什么一起走。
- **OC 私目标**：OC 自己的线，不服务主线也要成立。
- **主角目标**：原作主线，不能被 OC 替换。
- **冲突点**：两个私目标什么时候打架。
- **退出条件**：什么情况下 OC 会离开、被赶走、或主动分头。
- **底线**：什么事他绝不做；碰了会翻脸、离开，还是忍？

没有共同目标，跟不住；没有私目标，是挂件；没有冲突点，没张力。

### 4. 关系节拍

每 3–5 章至少走一次，不要只靠并肩打怪：

**靠近**（共享信息/秘密/住处/伤口）→ **摩擦**（方法、价值观、旧身份、谁说了算）→ **试探**（主角给任务，OC 违抗一次）→ **代价**（为对方损失什么）→ **新平衡**（关系变一点，但不彻底解决）。

关系是进两步退一步。不要每章发糖，也不要每章吵架。

### 5. 双人场景五问

写每场戏前，先答：

1. 主角本场想要什么？
2. OC 本场想要什么？
3. 两人方法哪里不同？
4. 谁先让步，为什么？
5. 结束后谁欠谁、谁防谁？

禁止：OC 全程解说、主角全程观众、两人永远意见一致。

### 6. 防脱离五查

- 主角有没有主动留 OC？
- OC 有没有私目标、私关系、非剧情生活？
- 主线关键场景，OC 是否至少在场一半？不要连续两章只在电话/回忆里出现；在场不等于出手。
- OC 不在场时，主角的戏照样成立吗？是，OC 可能多余；否，检查是否过度依赖。
- OC 有没有一次反对主角，并为此承担后果？

### 7. 防抢戏

- 关键选择让主角做；OC 可以影响，不能代替。
- 主角至少保留一场高光；OC 的高光要有代价。
- 主角的敌人由主角解决；OC 解决自己的敌人。
- 主角团里其他成员也要有作用，不要让 OC 取代整个团队。
- 不要让所有角色都更喜欢 OC。
- 主角可以更强、更对、更受欢迎，OC 不必处处压一头。

### 8. 同伴位常见崩法

| 崩法 | 表现 | 修法 |
| --- | --- | --- |
| 挂件 | 只附和、被救、夸主角 | 给私目标，给一次拒绝 |
| 保姆 | 所有问题都由 OC 解决 | 限制能力，把关键选择还给主角 |
| 跟班 | 没有自己的生活、钱、住处、习惯 | 补非剧情关系和日常 |
| 抢主线 | OC 变成真正主角 | 主线选择还给主角，OC 改走支线 |
| 粘人 | 两人永远不分开 | 设计分头行动、误会、独立线 |
| 空降信任 | 主角立刻交底 | 信任分期：先给任务，再给秘密 |
| 单向付出 | 一直 OC 救主角，或一直主角救 OC | 互欠、互换、互相拖累 |
| 恋爱脑 | 同行只为谈恋爱 | 先有共同目标，再谈感情 |

### 9. 分离测试

故意设计一次“必须分开”的剧情：主角走主线，OC 处理私事。两边都要能独立成立。然后再写一次“主动选择同行”，关系才算升级，而不是习惯。

## 九、输出

### 改编方案

```markdown
**Logline**：一句话，OC 想要什么，撞上了原作的什么。

**不改的锚点**（5–8 条）
- 事件 + 为什么不能动

**分叉点**
- 时间、地点、人物、OC 做了什么

**改动表**
| 事件 | 原 canon | 改成 | 动因 | 阶次 | 受影响的人 | 代价 |

**新冲突**
- OC 的存在带来了什么新问题、新敌人、新责任

**角色反应**
| 原作角色 | 原本会怎样 | 现在会怎样 | 为什么 | 关系变化 |

**章节节拍**
- 每章：压力 → 选择 → 代价 → 新问题

**风险与补丁**
- 最容易被读者挑出的三个漏洞，以及怎么补
```

### 随行同伴方案

```markdown
**同行契约**：共同目标 + 主角主动留人的动作
**主角为什么留他**：具体到利益、人情或麻烦，不写“因为他是主角”
**功能位**：镜子 / 反衬 / 补位（至少两个，写清代价）
**目标三角**
- 共同目标：
- OC 私目标：
- 主角目标：
- 冲突点：
- 退出条件：
- 底线：

**关系节拍**：第 X 章靠近 → 第 X 章摩擦 → 第 X 章试探 → 第 X 章代价 → 第 X 章新平衡

**分离测试**：分开时两边各自成立吗？谁主动要求重新同行？
```

### 场景正文

写具体场面时，先标三行（不输出给读者）：

- OC 此刻知道什么、不知道什么。
- 在场的人各自想要什么。
- 这一场结束后，谁的关系/局势变了。

然后把正文交给 `novel-prose` 的规则写：短句、动作、潜台词、不总结。

### 一致性检查

- 原作事实有没有被改？改了有没有标？
- 人物说话像不像本人？
- 能力有没有超过设定上限？
- 时间线够不够？
- 谁知道什么，符不符合传播速度？
- 随行时，主角有没有主动留人？OC 有没有连续两章掉线？
- 主题还在不在？

## 十、自检

1. OC 有没有“作者亲妈”光环：好事全归他，坏事不沾身？
2. 原作角色是不是 OOC 地喜欢、服从、嫉妒 OC？
3. 有没有抢别人的关键高光？抢了之后补偿了什么？
4. 每个改动都有代价吗？
5. 反派有没有降智？
6. 时间线够人物赶路、疗伤、传信吗？
7. 信息传播是不是太快？
8. 删掉 OC，这个故事还成立吗？如果完全成立，OC 就是多余的；如果完全不成立，OC 可能已经压垮原作。
9. 读者能不能说出“为什么非得是这个 OC”？
10. 感情线有没有跳过过程？拆 CP、改设定有没有标 AU？
11. 随行模式下，主角有没有主动留 OC？还是 OC 自己硬贴上去？
12. OC 有没有私目标、私关系、不在场时也能成立的线？
13. OC 有没有反对过主角一次，并为此付出代价？
14. OC 不在场的那几章，主角的戏是不是照样好看？
15. 主线关键场景里，OC 的在场率够吗？有没有连续两章掉线？

## 十一、一个最小示例

假设原作第 12 话：A 在天台被 B 推下，生死未卜。

OC：C，A 的旧友，能力是“短距离回退 10 秒”，代价是偏头痛和丢失回退前的记忆。

**分叉点**：天台前 3 分钟，C 来找 A。

**轻改方案**：

- 一阶：C 回退一次，A 没被推下去，抓住栏杆；B 逃跑。
- 二阶：A 开始怀疑 C 怎么知道；B 提前暴露，派人盯 C；C 因为丢失记忆，不记得 B 的脸。
- 三阶：组织提前介入，原定第 20 话的清洗提前到第 16 话。

**不合理的写法**：C 时停救下 A，B 当场被抓，两人顺利在一起。没有代价，反派降智，后面所有冲突作废。

**代价**：C 每次回退都失去 10 秒记忆；他救了 A，却不记得凶手长什么样。A 感激他，也开始怕他。

### 随行版最小示例

原作：A 要潜入敌对组织，查失踪的弟弟。

OC：C，能读被烧过的残页，但每读一次，会忘掉自己的一段记忆。C 想查哥哥失踪，和 A 同路。

- **同行契约**：共同目标（同一组织）+ 互补（C 读残页，A 有内部路线）+ 外力（两人都被通缉）。A 主动留 C：需要他的能力，也因为 C 让他想起自己的弟弟。
- **功能位**：镜子（C 为查亲人愿意忘事，照出 A 的执念）+ 补位（读残页），代价是失忆。
- **分歧**：A 要正面闯，C 要拿情报换路线；C 私下去换，害 A 受伤。
- **关系节拍**：第 3 章靠近（共享残页）→ 第 5 章摩擦（方法不同）→ 第 7 章试探（A 让 C 保管钥匙，C 违抗）→ 第 9 章代价（C 忘掉哥哥的脸，救 A）→ 第 10 章新平衡（A 替他瞒着队伍，但开始防他）。
- **分离测试**：C 单独查哥哥，A 单独走主线，两边都成立；最后 C 主动回来，不是因为没地方去，是因为选择 A。

不合理的写法：C 全程跟着 A，A 说什么他做什么，所有危险 C 解决，A 只负责感动。这是挂件，不是同伴。
