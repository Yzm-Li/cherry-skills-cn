# 随行同伴模式手册

OC 不是来客串的，是要跟在原作主角身边走很长一段路。难点不在“怎么让他出场”，在**怎么让他一直有理由在场、有事情可做、有架可吵，又不会把主角挤成观众**。

---

## 一、先过“同行契约”

OC 能长期留在主角身边，至少满足两条，其中一条必须是主角主动。

| 绑定 | 要写清楚 | 反例 |
| --- | --- | --- |
| 共同目标 | 两人短期或长期要去的方向重叠 | “刚好同路” |
| 互补 | OC 补主角的盲区，主角补 OC 的缺口 | OC 全能，主角只需要他 |
| 人情/责任 | 救过、欠过、答应过、被托付 | “主角人好” |
| 外力 | 通缉、契约、任务、同住、同队 | 没有原因地住一起 |
| 情感 | 信任、好奇、愧疚、吸引 | 一见钟情 |
| 分开代价 | 分开会失去什么，且马上发生 | “分开也能活” |

### 主角主动留人的五种动作

只写“OC 跟着主角”不算。主角必须做一次动作：

1. **邀请**：主角开口让他留下。
2. **默许**：主角不赶他走，还给他留了位置。
3. **挽留**：OC 要走，主角找理由留下他。
4. **利用**：主角需要他的能力，明说或不说。
5. **监视**：主角不信任他，放在身边看着。

每种动作都要有代价：

- 邀请 = 主角要为他担保。
- 默许 = 队伍里有人不满。
- 挽留 = 主角欠他一次，或暴露自己的需要。
- 利用 = 被 OC 发现后关系破裂。
- 监视 = 主角要分心，且可能被反利用。

### 硬凑同行的四个信号

- 主角没有做过任何留人动作。
- OC 的同行理由只有“我想跟着”。
- 两人没有共同目标，也没有互补。
- 分开对剧情没有任何影响。

出现两个，就要重写同行契约。

## 二、同伴位 OC 卡补充

在普通 OC 卡上，再加九项：

```markdown
## 同行信息
- 和主角的共同目标：
- 主角为什么留他：
- 他为什么留下：
- 他补主角什么，主角补他什么：
- 他对主角的第一印象（可能是错的）：
- 主角对他的第一印象（可能是错的）：
- 他在队伍里的位置：谁听他的，谁不服：
- 分开会失去什么：
- 什么情况下他会走：

## 私生活
- 钱从哪来：
- 住哪：
- 不打架的时候做什么：
- 和主角团之外的人有什么关系：
- 身体/习惯/忌讳：

## 声音
- 对主角的称呼：
- 生气时怎么说话：
- 沉默时做什么：
- 绝不会说的一句话：
```

### 第一印象要错

两个人都要对彼此有误判，后面才有“重新认识”的空间。

- OC 以为主角冷静，其实主角是怕；
- 主角以为 OC 贪钱，其实 OC 在还债；
- OC 以为主角是好人，后来发现主角也会见死不救；
- 主角以为 OC 无害，后来发现 OC 撒过谎。

没有误判，关系就只剩“越来越熟”，没有转折。

### 人物锚点（防 OC 自己 OOC）

- 他相信自己是什么样的人？
- 别人说他是什么样的人？
- 他最不愿承认的事是什么？
- 压力下他会做什么，事后会不会后悔？
- 他绝不会做什么？
- 遮住名字，能不能认出他的台词和选择？

同伴位最容易犯的错，是让 OC 为了留在主角身边，变得什么都能接受。给他一条不能碰的底线，同行才有代价。

## 三、功能位：至少占两个

| 功能位 | 作用 | 写法 | 代价 | 失败样子 |
| --- | --- | --- | --- | --- |
| 镜子 | 照出主角不愿承认的一面 | OC 做主角想做不敢做的事，或说出主角不敢承认的话 | 主角会恼羞，关系紧张 | OC 变成人生导师 |
| 反衬 | 同一问题做不同选择 | 两人方法相反，结果各有得失 | 谁都不全对 | OC 只是唱反调 |
| 补位 | 补主角缺的能力/视角/关系 | OC 有主角没有的入口，但有条件 | 能力有上限，或欠人情 | OC 变成万能工具 |

规则：

- 至少两个功能位，不能只有“打手”。
- 补位不能补掉主角的核心能力；主角的主线问题必须由主角解决。
- 镜子不能变成说教；让主角自己得出答案。
- 反衬不能每次都是 OC 对；至少让 OC 错一次。

---

## 四、目标三角

```text
        共同目标
       /        \
OC 私目标 —— 主角目标
       \        /
        冲突点
```

### 四个格子

| 格子 | 要写什么 | 测试 |
| --- | --- | --- |
| 共同目标 | 两人一起走的方向 | 去掉这个目标，同行还成立吗？ |
| OC 私目标 | OC 自己的线 | 主角不在场，这条线能独立推进吗？ |
| 主角目标 | 原作主线 | OC 能代替主角完成吗？不能就对了 |
| 冲突点 | 两个私目标何时打架 | 最近三章，两人有没有一次真正的分歧？ |

### 冲突的四个层级

从轻到重，不要一直停在同一层：

1. **方法冲突**：目的相同，做法不同。吵完还能一起走。
2. **优先级冲突**：先救谁、先查哪条线。要牺牲一个。
3. **价值观冲突**：底线不同。可能分道扬镳。
4. **忠诚冲突**：OC 要在主角和旧关系/阵营之间选。最伤。

每 10 章至少升一层。一直停在方法冲突，关系不会真正变化。

### 退出条件

提前写清楚：

- 什么情况下 OC 会主动离开？
- 什么情况下主角会赶他走？
- 什么情况下两人必须分头？
- 离开后，什么事件会让他们重新走到一起？

没有退出条件，同行就变成“作者不让走”，读者会觉得假。

## 五、关系节拍

每 3–5 章走一次，不要只靠并肩打怪。

| 节拍 | 写什么 | 例子 |
| --- | --- | --- |
| 靠近 | 共享信息、秘密、住处、伤口、一顿饭 | 主角让 OC 睡里侧，自己守夜 |
| 摩擦 | 方法、价值观、旧身份、谁说了算 | OC 擅自放走俘虏，主角当众压他 |
| 试探 | 主角给任务，OC 违抗一次；或 OC 试探主角底线 | 主角让 OC 保管钥匙，OC 偷偷配了一把 |
| 代价 | 为对方损失什么，且真的失去 | OC 用掉一段记忆救主角；主角为保 OC 向敌人低头 |
| 新平衡 | 关系变一点，但不彻底解决 | 主角开始替他瞒，但也开始防他 |

### 关系温度计

用 -3 到 +3 标每章关系，不要一直 +3：

- **+3**：可以把命交给他。
- **+2**：信任，但有关键隐瞒。
- **+1**：合作，互相有用。
- **0**：互相观察。
- **-1**：不满，勉强同行。
- **-2**：猜忌，随时翻脸。
- **-3**：敌对，只是还没动手。

关系要有起伏。长期 +3 会让后面所有冲突失效；长期 -3 会让读者问“为什么不分开”。

### 进两步退一步

- 不要每章发糖：信任来得太容易，后面不值钱。
- 不要每章吵架：读者会累，而且显得两人没成长。
- 每次靠近，都要付一点代价；每次摩擦，都要留下一个未解决的问题。

## 六、双人场景写法

### 写前五问

1. 主角本场想要什么？
2. OC 本场想要什么？
3. 两人方法哪里不同？
4. 谁先让步，为什么？
5. 结束后谁欠谁、谁防谁？

### 四种双人场景

| 场景 | 目的 | 不能缺 |
| --- | --- | --- |
| 并肩 | 建立默契 | 一个只有两人知道的小细节 |
| 分歧 | 制造张力 | 两人都有道理，且都付代价 |
| 交换 | 关系推进 | 交换的不只是情报，还有把柄/人情 |
| 分离 | 验证独立 | 分开后各自能立住，重聚有变化 |

### 视角与台词

- 长篇以主角视角为主，OC 视角为辅；不要让 OC 变成全程导游。
- 每场至少给主角一个主动选择，不要让他只负责反应。
- 对话要有“没说出口的那句”；OC 和主角都要有隐瞒。
- 两人意见完全一致时，这场戏通常可以删。

### 场景模板

```markdown
**本场目标**：主角要____，OC 要____。
**方法冲突**：主角想____，OC 想____。
**谁先让步**：____，因为____。
**代价**：____失去了____。
**关系变化**：从____到____，但____还没解决。
```

## 七、长篇同行弧

```text
相遇 → 试探 → 绑定 → 摩擦 → 分裂 → 重聚 → 并肩 → 代价 → 新平衡
```

| 阶段 | 章数参考 | 核心问题 |
| --- | --- | --- |
| 相遇 | 1–3 章 | 为什么要一起走？ |
| 试探 | 3–8 章 | 对方能不能信？ |
| 绑定 | 8–15 章 | 共同目标成立了吗？ |
| 摩擦 | 15–25 章 | 两人哪里不合？ |
| 分裂 | 25–35 章 | 什么底线被踩了？ |
| 重聚 | 35–45 章 | 为什么回来？ |
| 并肩 | 45–60 章 | 能不能把后背交给对方？ |
| 代价 | 60–75 章 | 为了同行失去什么？ |
| 新平衡 | 75 章以后 | 关系变成什么样？ |

不是每篇都写满；短篇可以只写“相遇→试探→绑定→摩擦→新平衡”。

### 每 10 章检查

- 两人的关系温度有没有变化？
- OC 的私目标推进了吗？
- 主角的主线推进了吗？
- 有没有一次真正的分歧？
- 有没有一次“分开也能活”的证明？

## 八、分离测试

### 为什么要分离

一直黏在一起，读者看不出两人是“选择同行”还是“没地方去”。分离一次，才能证明：

- 主角没有 OC 也能走主线。
- OC 没有主角也能活。
- 重聚是选择，不是习惯。

### 怎么写

1. 给一个必须分开的理由：任务、伤、误会、立场、家人。
2. 分头行动 1–3 章，两边各自推进。
3. 两边都要有独立的压力和选择，不能一边等另一边来救。
4. 重聚时，至少有一件事变了：信息、关系、立场、代价。
5. 重聚要有人主动：主角去找 OC，或 OC回来，不能“刚好遇到”。

### 分离失败的样子

- 分开一章就重逢，什么都没变。
- OC 分开后什么都不做，只等主角。
- 主角分开后剧情停摆，只等 OC。
- 重聚靠巧合，不靠选择。

## 九、防抢戏与防挂件

### 主角不能变观众

- 关键选择让主角做；OC 可以影响，但不能代替。
- 主角至少保留一场高光；OC 的高光要有代价。
- 主角的敌人由主角解决；OC 解决自己的敌人。
- 主角可以更强、更对、更受欢迎；OC 不必处处压一头。
- 主角的成长弧不能交给 OC 完成；OC 只能催化。

### OC 不能变挂件

- OC 要有私目标，且真的推进。
- OC 要有一次拒绝主角。
- OC 要有非剧情生活：钱、住处、习惯、朋友、身体。
- OC 要有一次失败或误判，并承担后果。
- OC 要知道一些主角不知道的事，也要有主角知道而他不知道的事。

### 好感分配

不要所有角色都喜欢 OC。至少留：

- 一个始终不服他的人。
- 一个利用他的人。
- 一个怕他的人。
- 一个只喜欢主角、对 OC 无感的人。

### 在场率

“跟着主角”不等于每场都出手，但也不能长期掉线：

- 主线关键场景，OC 至少在场一半。
- 不要连续两章只在电话、回忆、别人转述里出现。
- 在场可以只是看着、反对、拖后腿、收拾残局，不必每次都解决问题。
- OC 缺席的章节，要写清楚他去做什么，并且主角线能独立成立。

## 十、十四种崩法与修法

| 崩法 | 表现 | 原因 | 修法 |
| --- | --- | --- | --- |
| 挂件 | 只附和、被救、夸主角 | 没有私目标 | 给目标，给一次拒绝 |
| 保姆 | 所有问题都由 OC 解决 | 能力太全 | 限制能力，关键选择还给主角 |
| 跟班 | 没有生活、钱、住处、习惯 | 只围绕主角转 | 补非剧情关系和日常 |
| 抢主线 | OC 变成真正主角 | 主角选择被代劳 | 主线选择还给主角，OC 走支线 |
| 粘人 | 两人永远不分开 | 没有分离测试 | 设计分头行动、误会、独立线 |
| 空降信任 | 主角立刻交底 | 跳过关系过程 | 信任分期：任务→秘密→把柄 |
| 单向付出 | 一直 OC 救主角，或反过来 | 没有互欠 | 互换、互救、互相拖累 |
| 恋爱脑 | 同行只为谈恋爱 | 没有共同目标 | 先有共同目标，再谈感情 |
| 全员好感 | 所有人都喜欢 OC | 作者亲妈 | 留不服、利用、害怕的人 |
| 工具人主角 | 主角只负责感动/被救 | OC 太强 | 主角做关键选择，OC 付代价 |
| 没有分歧 | 两人永远一致 | 怕破坏关系 | 每 10 章升一层冲突 |
| 分离即散 | 分开后剧情停摆 | 一边过度依赖 | 两边各自推进 |
| 重逢无变化 | 重聚后关系照旧 | 没有代价 | 重聚必须带来信息/关系/立场变化 |
| 设定堆砌 | 能力、身份、关系一大堆 | 只写标签不写选择 | 只留能改变选择的设定 |

## 十二、自检清单

- [ ] 主角有没有主动留 OC 的动作？
- [ ] 同行契约至少两条，且有一条是主角主动吗？
- [ ] OC 有没有私目标，且真的推进？
- [ ] OC 有没有非剧情生活？
- [ ] OC 有没有一次拒绝/反对主角，并承担后果？
- [ ] 主角有没有至少一场独立高光？
- [ ] 关键选择是不是主角做的？
- [ ] 两人有没有一次真正的分歧？
- [ ] 关系温度有没有起伏？
- [ ] 主线关键场景，OC 的在场率够吗？有没有连续两章掉线？
- [ ] 有没有一次分离测试？
- [ ] 重聚是不是选择，不是巧合？
- [ ] 所有角色是不是都太喜欢 OC？
- [ ] OC 不在场时，主角的戏照样成立吗？

## 十三、示例

### 成功版

原作：A 要潜入敌对组织，查失踪的弟弟。

OC：C，能读被烧过的残页，但每读一次，会忘掉自己的一段记忆。C 想查哥哥失踪，和 A 同路。

| 项 | 内容 |
| --- | --- |
| 共同目标 | 查同一个组织 |
| 互补 | C 读残页，A 有内部路线 |
| 外力 | 两人都被通缉 |
| 分开代价 | C 失去保护，A 失去读残页的人 |
| 主角主动 | A 邀请 C 同行，并替他担保 |

- **功能位**：镜子（C 为查亲人愿意忘事，照出 A 的执念）+ 补位（读残页），代价是失忆。
- **分歧**：A 要正面闯，C 要拿情报换路线；C 私下去换，害 A 受伤。
- **关系节拍**：第 3 章靠近（共享残页）→ 第 5 章摩擦（方法不同）→ 第 7 章试探（A 让 C 保管钥匙，C 违抗）→ 第 9 章代价（C 忘掉哥哥的脸，救 A）→ 第 10 章新平衡（A 替他瞒着队伍，但开始防他）。
- **分离测试**：C 单独查哥哥，A 单独走主线，两边都成立；最后 C 主动回来，不是因为没地方去，是因为选择 A。

### 失败版与修法

失败版：C 全程跟着 A，A 说什么他做什么；所有危险 C 解决，A 只负责感动；队伍所有人都喜欢 C；两人从不吵架。

问题：没有私目标、没有分歧、没有代价、主角变观众。

修法：

1. 给 C 一个和主线冲突的私目标：他想找哥哥，但哥哥可能正是伤害 A 弟弟的人。
2. 让 C 瞒着 A 去见哥哥，导致 A 的计划失败。
3. 让 A 当众赶 C 走；C 离开后单独查哥哥，A 单独走主线。
4. 重聚时 C 带着关键情报回来，但 A 不再完全信他。
5. 关系从 +2 降到 -1，再慢慢回到 +1；不是回到 +3。

## 十四、一页纸
