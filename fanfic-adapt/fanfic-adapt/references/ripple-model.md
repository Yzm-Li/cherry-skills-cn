# 涟漪模型

## 一、三阶影响

```text
OC 的一个选择
  → 一阶：直接改变的事件
    → 二阶：相关角色的反应、关系、阵营
      → 三阶：组织、世界、终局
```

### 一阶

写“发生了什么”：

- OC 救了谁、挡了什么、提前泄露了什么、拿走了什么。
- 时间、地点、在场的人。
- 直接后果：谁受伤、谁逃走、什么东西丢了。

### 二阶

写“人怎么反应”。每个受影响的人三选一：

- **接受**：调整计划，和 OC 合作。
- **抵抗**：报复、举报、设局。
- **利用**：拉拢、试探、拿 OC 当刀。

至少写两个不同反应，不要所有人一个态度。

二阶还要写关系变化：

- 信任增加/减少？
- 谁欠谁人情？
- 谁开始怀疑 OC 的秘密？
- 哪对关系被撬动？

### 三阶

写“世界怎么变”：

- 组织提前介入/清洗/追捕。
- 规则被触发：禁术、法律、门派规矩。
- 权力平衡变化：某派失势，某派上位。
- 公共叙事变化：谣言、舆论、官方说法。
- 终局变量：最终战的条件变了。

只写一阶是“改事件”，写到二阶才是“改剧情”，写到三阶才是“改世界”。

## 二、惯性

不是所有 canon 都会立刻变。给每个锚点标惯性：

| 惯性 | 特征 | 改编方式 |
| --- | --- | --- |
| 高 | 结构性压力：制度、利益、仇恨、世界规则 | 事件会以另一种形式发生，改时间/地点/执行者 |
| 中 | 依赖关键人物的选择 | 选择变了，事件可能推迟、缩小、转移 |
| 低 | 依赖巧合、单个人物、临时起意 | 可以被取消或替换 |

高惯性例子：

- 反派要夺权，不会因为 OC 出现就不夺；他会换方法。
- 门派要清理门户，不会因为 OC 求情就取消；可能改成秘密执行。
- 灾难要发生，OC 只能改变伤亡，不一定能阻止。

如果你让高惯性事件“因为 OC 来了就没发生”，要给出同等分量的替代压力，否则故事会泄气。

## 三、信息传播

```text
亲眼看见 → 在场的人
听说 → 关系网 → 阵营 → 组织 → 公众
```

每个信息问：

- 谁亲眼看见？
- 谁只会听说？听谁说的？
- 谁不信？为什么？
- 谁有动机压下去/放大？
- 传到关键人物耳朵里，需要多久？

传播延迟参考：

| 范围 | 时间 |
| --- | --- |
| 同一现场 | 立刻 |
| 同一组织 | 几小时到一天 |
| 同一城市/门派 | 一到三天 |
| 跨区域/公众 | 几天到几周 |

不要让人物“刚好知道”不该知道的事。

## 四、权力校准

OC 变强，世界要跟着变：

- **对手升级**：更强的敌人、更聪明的打法、更狠的代价。
- **规则反制**：组织修改规则、设专门克制。
- **资源争夺**：OC 的能力变成资源，各方来抢。
- **责任增加**：能救人，就意味着救不过来的人会怪他。

如果 OC 能一招解决，冲突就不成立。给他：

- 冷却/代价/条件。
- 误判/情报错误。
- 道德困境：救一个还是救一群。
- 暴露风险：用了就会被盯上。

## 五、时间成本

改编后重排时间线：

```markdown
| 时间 | 事件 | 谁在场 | 谁知道 | 备注 |
```

检查：

- 上一件事结束后，人物来得及赶到吗？
- 伤/损失恢复了吗？
- 信息传到该听的人耳朵里了吗？
- 决策需要开会/请示/准备吗？
- OC 的能力冷却好了吗？

## 六、涟漪表

```markdown
| 改动 | 一阶 | 二阶（谁反应/怎么反应） | 三阶（世界/终局） | 代价 |
| --- | --- | --- | --- | --- |
| OC 救下 A | A 活，B 逃 | A 怀疑 OC；B 派人盯 OC | 组织提前介入 | OC 暴露能力，被通缉 |
```

每行都要有“代价”。没有代价的改动，是爽点，不是剧情。

## 七、反作用

OC 做好事，也会产生反作用：

- 被救的人可能依赖、怀疑、嫉妒、恩将仇报。
- 敌人会调整策略，不再用原来的打法。
- 组织会注意到异常，开始调查。
- 旁观者会误传，形成新的舆论。
- OC 自己会付出代价：伤、暴露、失去记忆、欠人情。

写改编方案时，至少写一条反作用。

## 八、示例

原作：A 在第 12 话被 B 推下天台。

OC：C，能回退 10 秒，代价是偏头痛和丢失回退前的记忆。

| 阶次 | 内容 |
| --- | --- |
| 一阶 | C 回退一次，A 抓住栏杆，B 逃跑 |
| 二阶 | A 怀疑 C 怎么知道；B 派人查 C；C 不记得 B 的脸 |
| 三阶 | 组织提前介入，原定第 20 话的清洗提前到第 16 话 |
| 代价 | C 暴露能力，被两方盯上；A 开始怕他 |

不合理版本：C 时停救 A，B 被抓，两人在一起。没有代价，反派降智，后续冲突作废。

## 九、检查

- [ ] 一阶、二阶、三阶都写了吗？
- [ ] 高惯性事件有没有替代形式？
- [ ] 信息传播速度合理吗？
- [ ] 对手有没有升级/反制？
- [ ] 时间线够人物行动吗？
- [ ] 每个改动都有代价吗？
- [ ] 有没有至少一条反作用？
