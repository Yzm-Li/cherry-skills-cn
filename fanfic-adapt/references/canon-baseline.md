# Canon 基线

## 一、来源层级

1. **原作正文**：最高。
2. **作者访谈/设定集/官方指南**：次之，注意时间与版本。
3. **官方改编**：动画/影视/游戏，可能和原作冲突，标版本。
4. **Wiki/粉丝整理**：只当索引，关键事实回原作核。
5. **Fanon（粉丝共识）**：可以用，但标“非原作”。

冲突时以原作正文为准；原作本身有版本差异时，标清楚用哪版。

## 二、锚点事件

选 5–8 个承重事件。每个填：

```markdown
### 锚点：第 12 话 天台
- 发生了什么：
- 为什么会发生（结构性压力）：
- 谁在场，谁做了什么选择：
- 后果：
- 惯性：高/中/低
- 能不能改：能改形式，不能改后果 / 可以取消 / 必须保留
```

判断锚点的标准：

- 删掉它，后面的故事还成立吗？不成立，才是锚点。
- 它是靠某个人物的选择，还是靠制度/世界规则？后者惯性更高。
- 它是名场面，还是因果节点？名场面可以换形式，因果节点不能随便删。

## 三、人物内核卡

```markdown
### 角色：A
- 表面想要：
- 真正需要：
- 最怕：
- 底线：
- 说话方式：
- 关键时刻会怎么选：
- 关系弧：
- 绝不会做的事：
```

改编时只改“处境”，不改这四样：想要、最怕、底线、关键时刻的选择逻辑。

### OOC 检查

- 这句话，他会说吗？
- 这个选择，符合他的底线吗？
- 他为什么突然信任 OC？给出过程。
- 他为什么突然放弃目标？给出代价。

## 四、世界规则

| 项 | 要确认 |
| --- | --- |
| 能力体系 | 上限、代价、冷却、能否被普通人看见 |
| 社会结构 | 谁掌权、谁被压迫、规则怎么执行 |
| 经济/资源 | 钱、物资、信息怎么流动 |
| 时间/空间 | 赶路、通信、疗伤、调查各要多久 |
| 禁忌 | 打破规则会有什么后果 |
| 组织 | 阵营、层级、内部矛盾 |

世界规则不是背景板，是冲突的边界。OC 要破规则，先让读者知道规则。

## 五、时间线

```markdown
| 日期/话数 | 事件 | 参与者 | 谁知道 | 备注 |
```

要点：

- 事件发生时间和揭露时间分开。
- 人物不知道的事，不要写进他们的决策。
- 赶路、疗伤、传信需要时间。
- 改编后重新排一遍时间线，不要只改事件不改日期。

## 六、不改清单

动笔前写清楚：

- 哪些人物内核不能变？
- 哪些锚点必须保留（可以换形式）？
- 哪些关系弧不能拆？
- 哪些世界规则不能被 OC 打破？
- 哪些主题不能被爽点盖掉？

这张清单是改编的边界。越界要明确标“AU/重改”，不要假装还是原作向。

## 七、常见错误

| 错误 | 后果 | 修正 |
| --- | --- | --- |
| 把 fanon 当 canon | 设定冲突 | 回原作核 |
| 只记名场面，不记因果 | 改编变拼贴 | 补“为什么会发生” |
| 让人物知道不该知道的事 | 逻辑崩 | 查时间线和信息传播 |
| 为了 OC 改人物底线 | OOC | 改处境，不改内核 |
| 忽略世界规则 | 金手指失控 | 先写规则，再写例外 |
