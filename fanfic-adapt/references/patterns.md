# 六种 OC 类型与改编规模

## 一、先选类型

| 类型 | 核心 | 好看在哪 | 最容易崩 |
| --- | --- | --- | --- |
| 插入型 | 世界里多一个人 | 旁观者视角、补线、改变小节点 | OC 多余，删了也不影响 |
| 替换型 | 取代某个原作角色 | 熟悉的剧情被重新演绎 | 功能缺失、粉丝情感 |
| 关系型 | 与原作角色有旧关系 | 改写动机、联盟、背叛 | “为什么原作没提” |
| 信息型 | 穿越/重生/预知 | 信息差、决策博弈 | 全知全能、直接通关 |
| 能力型 | 带来新能力/技术/资源 | 力量平衡变化、新冲突 | 金手指横扫、反派降智 |
| 阵营型 | 站在对立面 | 立场冲突、双向塑造 | 脸谱化、强行洗白 |

### 选择决策树

1. 用户想保留主线吗？想 → 插入型/轻改；不想 → 替换/重改。
2. OC 的核心看点是什么？关系 → 关系型；信息 → 信息型；能力 → 能力型；立场 → 阵营型。
3. 原作里有没有一个“缺位”？有 → 插入/替换；没有 → 关系/阵营，别硬塞。
4. 用户能接受多大改动？不能 → 轻改；能 → 中改；要重构世界 → AU。

## 二、六种类型详解

### 1. 插入型

**核心**：原作世界多了一个人，主线大体照常。

**必补**：为什么原作没提这个人？

可选答案：

- 不在场：事件发生时他在别处。
- 化名/伪装：原作只知道他的另一个身份。
- 被忽略：他是小人物，原作视角没拍到他。
- 被删记忆：原作角色不记得他（慎用，容易变万能解释）。

**崩法**：OC 只是围观，所有关键选择仍由原作角色做，删掉他故事不变。

**补丁**：让他改变一个“小但会扩散”的节点：一句提醒、一次迟到、一件被拿走的物品。

### 2. 替换型

**核心**：OC 站在某个原作角色的位置上。

**必补**：

- 被替换角色的功能谁承担？推动剧情、提供信息、当反派、当牺牲品。
- 原作角色对他的感情怎么转移？不要无缝继承。
- 粉丝情感：被替换的角色不能凭空消失，要给交代。

**崩法**：OC 拿了位置，没拿责任；原作角色像失忆一样接受。

**补丁**：把被替换角色的核心功能拆给两个人，让 OC 只承担一部分，剩下的人补位。

### 3. 关系型

**核心**：OC 和某个原作角色有旧关系（亲属、师徒、旧友、旧敌）。

**必补**：为什么原作没出现？

- 断联：多年不见，各有生活。
- 隐瞒：身份不能公开。
- 时间差：原作开始前刚分开。
- 立场：关系存在，但不能相认。

**崩法**：关系只用来发糖/加战力，不改变任何选择。

**补丁**：让这段关系成为原作角色的“软肋”或“不能碰的底线”，在关键选择时逼他付出代价。

### 4. 信息型

**核心**：OC 知道剧情（穿越、重生、预知、看过原作）。

**必补**：

- 知道多少？全知、部分、还是只知道大概？
- 记忆可靠吗？会记错、过时、被误导吗？
- 说出来谁信？不信怎么办？
- 蝴蝶效应什么时候让知识失效？

**崩法**：OC 全知全能，所有危机提前解决，原作角色变成工具人。

**补丁**：让知识有代价——说了会暴露、会害人、会改变未来；让他越快解决问题，越快失去优势。

### 5. 能力型

**核心**：OC 带来新能力、技术、资源，改变力量平衡。

**必补**：

- 上限、代价、冷却、条件。
- 谁能克制？
- 暴露后谁来找他？
- 为什么不用它解决最终问题？

**崩法**：金手指横扫，反派降智，冲突作废。

**补丁**：给能力加“不能用”的场景（人质、规则、代价、误判），让 OC 必须用别的方式赢。

### 6. 阵营型

**核心**：OC 站在原作主角的对立面，或夹在两个阵营之间。

**必补**：

- 他的立场怎么来的？利益、创伤、责任，不能只是“他是坏人”。
- 他的阵营有内部矛盾吗？
- 他有没有不能伤害的人？
- 他有没有可能倒戈？倒戈的代价是什么？

**崩法**：脸谱化反派，或毫无代价地洗白。

**补丁**：给他一个和主角共享的目标，但手段不同；让他每次选择都失去一点东西。

## 三、改编规模

### 轻改

- 只动一个小节点。
- 主线、结局、人物弧不变。
- 适合：插入型、关系型、短篇、单元剧。
- 风险：OC 像旁观者；要给 OC 一个不可替代的作用。

### 中改

- 动一个关键节点，主线走向不同。
- 保留核心冲突、人物内核、主题。
- 适合：大多数 OC 同人。
- 风险：涟漪收不住；先写三阶后果，再决定是否扩大。

### 重改/AU

- OC 的设定改写世界规则。
- 只保留精神内核或人物。
- 必须明确标 AU，不假装 canon。
- 适合：能力型、阵营型、长篇重构。
- 风险：需要重建设定、重排时间线、重写人物弧。

## 四、常见崩法

| 崩法 | 表现 | 处方 |
| --- | --- | --- |
| 玛丽苏/汤姆苏 | 好事全归 OC，坏事不沾身 | 加代价、加失败、让出高光 |
| 工具人化 | 原作角色只负责夸 OC/救 OC | 给他们自己的目标和选择 |
| 抢高光 | OC 解决所有关键场面 | 让出一场，或让别人完成最后一击 |
| 反派降智 | 反派突然变蠢 | 给反派情报、计划和反制 |
| 强行配对 | 不管人物弧，硬凑 CP | 先写关系变化的过程和代价 |
| 设定堆砌 | 能力、身份、关系一大堆 | 只留能改变选择的 |
| 原作失忆 | 人物忘了 OC 不该知道的事 | 查信息传播和时间线 |
| 结局作弊 | OC 突然觉醒新能力 | 能力提前埋线，代价提前写 |
