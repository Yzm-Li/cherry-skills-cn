# 切分规则

## 一、切分目标

每块满足三个条件：

1. **能独立读懂**：有足够的上下文，不依赖上一块原文。
2. **小到可控**：默认 1,200–2,000 汉字，不超过 3,000。
3. **边界自然**：不切断句子、对话往返、代码块、表格、条款。

## 二、边界信号

### 强信号（优先）

- 卷/章/节标题：`第X卷`、`第X章`、`第X节`、`Chapter N`、Markdown `#`。
- 特殊结构：`序章`、`楔子`、`尾声`、`后记`、`附录`。
- 场景分隔符：`***`、`* * *`、`———`、`◇`、单独一行的空白。
- 代码围栏：``` 与 ~~~。
- 表格起始行。
- 合同条款编号：`第X条`、`X.X`、`(a)`。

### 中信号

- 时间跳转：`三天后`、`第二天`、`翌日`、`傍晚`、`多年以后`、`回到……`。
- 地点跳转：段落首句出现新地点。
- 视角切换：段落首句换成一个新人物，并出现感知/心理动词。
- 话题切换：连续两段的实体重合度骤降。
- 对话群结束：连续对话后出现一段动作/环境描写。

### 弱信号

- 空行。
- 段首缩进（中文全角空格）。
- 列表开始/结束。

## 三、切分伪代码

```text
MAX = 2000  # 汉字
MIN = 300
TARGET = 1600

sections = parse_structure(text)          # 标题/章节/代码块
for s in sections:
    if len(s) <= MAX:
        emit(s)
        continue

    candidates = find_boundaries(s)       # 强/中/弱信号 + 段落/句子边界
    start = 0
    while len(s) - start > MAX:
        window_start = start + TARGET * 0.7
        window_end   = start + TARGET * 1.15
        cut = best_boundary(candidates, window_start, window_end)
        if cut is None:
            cut = nearest_paragraph(s, start + TARGET)
        if cut is None:
            cut = nearest_sentence(s, start + TARGET)
        emit(s[start:cut])
        start = cut

    emit(s[start:])
merge_small_chunks(MIN)                   # 小于 MIN 的并入相邻块
assign_ids_and_hashes()
```

`best_boundary` 取边界分最高、离目标字数最近的位置；同分时取更靠后的位置，避免块太碎。

## 四、边界分

```text
+3  显式标题/章节标记
+2  场景分隔符
+2  时间/地点跳转
+2  视角人物变化
+1  空行/段首缩进
+1  实体重合度骤降
-2  正在对话中间（引号未闭合）
-3  代码块/表格内部
```

## 五、绝对不能切的地方

- 一句话中间（除非单句超过 3,000 字，且无路可走）。
- 一组对话往返中间：宁可整组放一块，也不要在“他说”和“她答”之间切。
- 代码块、表格、引用块内部。
- 标题和它的第一段之间。
- 列表引导句和列表项之间。
- 合同的定义条款和引用它的条款之间（至少加互链）。
- 脚注/引用标记和它对应的正文之间。

## 六、特殊文本

### 超长段落

先按句号/问号/叹号切；仍超长，再按分号/逗号切。切完检查引号是否配对。

### 超长对话

按“对话群”切：一次连续对话（同一时间、同一地点、同一组人）为一块。换场景、换人、插入大段动作描写，才切。

### 表格

保留表头；按行分组切，每组重复表头。不要把一行拆开。

### 代码

按文件 → 类 → 函数切。每块保留：文件路径、import、函数签名、必要注释。代码围栏重新闭合。

### 合同

按“条”切；定义条款单独一块；每个义务/权利/例外尽量在同一块；跨块引用加 `links`。

### 聊天记录

按话题窗口切，10–20 轮为一块；不切断一问一答；把决定、负责人、截止时间留在同一块。

## 七、重叠策略

默认 0 重叠。

需要连续性时，按优先级：

1. **状态卡**：上一块的人物/时间/地点/未决问题，50–150 字。
2. **上一块摘要**：1–2 句。
3. **原文尾巴**：最后 1–2 句，100–200 字，仅限叙事。

不要用 500 字以上的原文重叠；那是重复付费，不是连续性。

## 八、质量检查

- [ ] 每块开头是完整句子，不是“他说”“但是”这种依赖上文的开头。
- [ ] 每块结尾在边界上，不是半句话。
- [ ] 每块有标题或首句摘要。
- [ ] 每块字数在 MIN–MAX 之间，超长块有理由。
- [ ] 没有块跨越两种视角/两个场景。
- [ ] 代码块、表格、对话群完整。
- [ ] 块 ID 唯一，哈希可复现。
- [ ] 所有块拼起来能覆盖原文（允许重叠，不允许缺口）。
