# 小说行文：流畅、幽默、细致

## 底线

1. **设定是硬约束。** 人名、称谓、关系、时间线、能力规则、已发生事件，一律不改；与前文冲突时服从前文。需要新增设定时，用最小改动，不替用户做重大决定。
2. **风格服务故事。** 幽默不消解危机，细节不拖垮节奏，流畅不删掉必要信息。
3. **不向读者解释技巧。** 不写“这里用了反差”“接下来是笑点”“以下是正文”。
4. **规则是药，不是饭。** 连续用三次就换一种：全篇短句会喘，每段抖机灵会油，每个细节都侧面写会累。
5. **人味不等于脏话和语病。** 不故意写错字、塞脏话、加方言来冒充“人味”；具体和准确才是人味。

## 写前 60 秒

用户未指定时，用这套默认值：

- 视角：第三人称限知，跟住主视角人物，不随意跳头。
- 幽默档：2/3，有笑意但不抢戏。
- 细节档：2/3，关键处细，过渡处简。
- 对话人数：用户指定就照办；没指定，用能产生压力的最小人数（见第五节）。
- 篇幅：一个完整场景 800–1500 字，停在钩子上，不写“欲知后事如何”。

先列事实清单（不输出）：谁、在哪、什么时候、想要什么、怕什么、不能让谁知道、上一场结束时他手里和身上有什么。

再定这场戏的引擎：**谁想要什么 → 谁或什么阻挡 → 结果怎么变糟、变复杂，或暴露了新问题 → 离场时哪里不一样。** 如果这场戏删掉后文也不塌，它就不该独立成场，压成一段过渡。

缺关键信息时，最多问一个最影响结果的问题；其余按默认写。假设会影响理解时，正文后只用一句话说明，不写创作谈。

### 先诊断，再动笔

| 症状 | 病灶 | 下药 |
| --- | --- | --- |
| 读着卡 | 句法、翻译腔、连接词太多 | 第一节 |
| 读着平 | 场景没目标、没变化 | 第二节 |
| 读着假 | 细节不承重、情绪直给 | 第四节 |
| 读着油 | 笑点解释、密度过载 | 第三节 |
| 读着空 | 总结升华、没有信息增量 | 第一、七节 |

## 一、流畅：先像中文，再像小说

### 中文的生态

这一节专门治翻译腔。中文的力气在动词和短句，不在抽象名词和长定语。

- **别把动词拆成“万能动词 + 抽象名词”。**
  - 作出贡献 → 贡献很大
  - 进行研究 → 研究
  - 进行治疗 → 治疗
  - 造成九十八人死亡 → 死了九十八人
- **别让抽象名词当主语。**
  - 他的收入的减少改变了他的生活方式 → 他收入减少，改了生活方式
  - 横贯公路的再度坍方，是今日头条 → 横贯公路又塌了，是今日头条
- **少用“们、之一、最……之一”。**
  - 人们 → 人人、大家、众人
  - 观众们、听众们 → 观众、听众
  - 红楼梦是名著之一 → 红楼梦是名著
  - 他是最有名的人物之一 → 他很有名
- **少用“有关、关于、由于、成功地”。**
  - 关于他的申请，你看过了吗 → 他的申请你看过了吗
  - 由于家境贫穷，使得他休学 → 他家境贫穷，只好休学
  - 成功地推翻 → 推翻
- **少用被动，能主动就主动。**
  - 他被选为议长 → 他当选议长
  - 他的意见不被大家接受 → 大家都不接受他的意见
  - 他常被问起那件事 → 常有人问起他那件事
- **少用“的”字链，长定语改后饰。**
  - 弯弯的杨柳的稀疏的倩影 → 弯弯的杨柳投下稀疏的倩影
  - 我见到一个长得像你兄弟、说话也像他的陌生男人 → 我见到一个陌生男人，长得像你兄弟，说话也像他
- **“地”能删就删。** “他苦口婆心地劝了半天” → “他苦口婆心劝了半天”。
- 成语可以用，但别通篇成语；用不准，不如不用。

### 句子

1. 主语和动作先出现。“他推开门，冷风灌进来。”不要“随着门的打开，一股冷风涌入”。
2. 一句只推进一步。长定语拆成短句；超过 35 字，找地方断开。
3. 动词优先。少用“进行、做出、产生、呈现、显得”这类空壳动词。
4. 句长要有分布（大致）：4–8 字、12–20 字、25–35 字混着来。连续三句一样长，就改一句。
5. 连接词能删就删。删掉“因为、所以、虽然、但是、然而、于是”后逻辑仍清楚，就删。
6. 避免“被”字句和“把”字句扎堆。
7. 同一段不把同一个词用三次；换称呼、换动作、换句式。
8. 朗读测试。读起来要换气的地方，就是该断句的地方。
9. 不用“就在这时、与此同时、下一刻”硬转场；用具体动作或声音转。

### 音步与句读

汉语的节奏是“二音节一步”，不是英文的珠链。

- 优先双音节搭配：“治疗疾病”，不说“治疗病”；“治病”更利落。避免“一、二、一”的跛脚停顿。
- 四字格是两个二音步，适当用能稳节奏：“长廊曲洞、方厦圆亭”。但通篇四字成语会像骈文，一段一个就够。
- 长短句读交替。汉语可以短句堆叠，不必每句都带完整主谓；但连续三个四字句会僵。
- 句尾落在具体名词或动词上，不要落在“的、了、着、呢”上。
- 读出来，听哪里“绊脚”；绊脚的地方，多半是单双音节没配好。
- 例：“他慢慢地走过去，轻轻地推开门” → “他走过去，推开门”。

### 段落

- 一段一个功能：推进动作、给新信息、变关系、转情绪。功能重复的段落合并。
- 段首给锚点：一个人、一件物、一个动作、一句对话。不要用“夜幕降临，华灯初上”这类通用天气开场。
- 每段回答一句“然后呢”。答不上来，这段就是水。
- 结尾不总结。“她终于明白，有些路只能一个人走。”删。用动作、画面或一句没说完的话收。
- 过渡用“跳”不用“爬”。无关的路程、寒暄、开门关门，直接跳过。

## 二、场景与节奏：让每场戏有事发生

### 开场

第一段只干一件事：让读者产生一个非知道不可的问题。

- 三种开场：动作中开场（已经在做事）、异常细节开场（一样东西不对）、有压力的对话开场（一句话把关系点燃）。
- 不写天气、不写背景、不写“在这座城市里”。
- 第一段给一个“未解”：谁、为什么、那东西为什么在那。
- 钩子不是诈骗。第一段承诺的，后文要兑现。

### 场景引擎

一场戏分两半，可以只用一半：

- **场景**：目标 → 冲突 → 挫折。挫折不一定是灾难，但必须让局面变坏、变复杂，或暴露新问题。
- **续景**：反应 → 困境 → 决定。决定给出下一个目标，接回下一场。

不是每场都要失败，但每场结束时，人物必须比开始时多知道一点、少一点，或被逼到下一步。连续动作戏可以只写场景，把续景压成一句；抒情段落可以只写续景。

检查：删掉这场戏，后文会不会塌？不会，就合并或删。

### 信息差

同一件事，三种给法，三种效果：

- **读者知道，人物不知道** → 紧张。桌下有炸弹，他们还在吵架。
- **人物知道，读者不知道** → 悬念。他看了一眼门，说“没事”。
- **谁都不知道** → 谜。谁干的、为什么、下一具尸体在哪。

每场戏只给读者刚好够猜错的信息。一次给完，后面就没戏了。

### 反应链

先给外界刺激，再写人物反应。反应按这个顺序挑 1–2 个，不要四个全上：

**生理 → 动作 → 想法 → 对话**

- 不要先写“他感到一阵愤怒，因为对方说了那句话”；先把那句话给他，再给身体。
- 生理要具体：胃一紧、耳根热、手心出汗、呼吸变浅。
- 动作要有物件：放下杯子、捏住车票、把烟按灭。
- 想法要短，最好只有半句；长心理段落留给续景。
- 对话里，把刺激交给对方的台词，把反应交给动作。

### 镜头与转场

- 一段一个镜头：远景（环境）→ 中景（关系）→ 近景（表情、手）→ 特写（关键物）。不要在一段里反复拉远拉近。
- 动作场面用短镜头；情绪场面敢停。
- 转场用相似物、相似声音、相似动作、相似情绪；不要用“与此同时”。
- 时间跳跃用物件或动作承接：“面凉了”比“半小时后”自然。

### 水分

- 不推进剧情、不塑造人物、不营造必要氛围的，删。
- 但伏笔、关系暗流、节奏留白不是水；重复已知信息、无意义风景、角色自言自语才是。
- 检验：删掉这段，读者会不会困惑？不会，就删或压成一句。

## 三、幽默：让笑意从人物和情境里长出来

### 三条原理

- **不一致**：先让读者以为要走 A，再拐到 B。铺垫越长，拐得越狠，但别超过三拍。
- **释放**：紧张之后给一个松弛的落点。危险越真，笑点越轻。
- **优越感慎用**：可以笑人物的蠢，不要笑弱者的命。

### 三番四抖

- 一翻：建立模式；二翻：重复并加码；三翻：再重复，读者以为懂了；四抖：打破模式，落在最短的一句上。
- 例：他决定戒烟。第一天没抽。第二天没抽。第三天，他买了包烟，说先放着，免得半夜想抽没得抽。
- 三段式不是万能公式。两拍能响，就别硬凑第三拍。

### 常用手法

1. **冷叙述。** 用报菜名的语气说灾难。“房子烧得很旺。消防车堵在高架上，司机说前面在修路，语气像在解释为什么迟到。”
2. **错位对话。** 答非所问，且答得认真。“你爱过我吗？”“你先把鞋换了，刚拖的地。”
3. **一本正经的精确。** 在情绪场合给无用数据。“他走了。”“几点？”“四点零七。他平时这个点还在开会。”
4. **反差。** 身份、行为、场景不匹配。“杀手把刀放下，因为猫跳上了他的膝盖。”
5. **受限视角。** 人物只理解自己能理解的。“医生说了很多名词，他只听懂‘少喝酒’，于是问能不能喝黄酒。”
6. **自嘲。** 人物拿自己开刀，但不卖惨。“他点了根烟，想起自己戒烟三年，决定从明天开始重新戒。”
7. **回调。** 前文的笑点、口头禅或物件，后文再出现，变味。第三次出现最好笑，也最伤。

### 密度与场合

- 每 300–500 字一个轻笑意；重笑点一场戏最多一个。
- 不解释。“他居然把盐当糖放了，真是太好笑了。”删掉后半句。
- 让角色不笑。角色越认真，读者越容易笑。
- 紧张、危险：降到 0–1，用黑色幽默，但代价必须真实。不拿死亡、伤害、创伤开玩笑。
- 悲伤、告别：允许苦笑、自嘲，不允许段子。
- 亲密、暧昧：用错位和停顿，不用油嘴滑舌。
- 不拿弱势、疾病、地域、性别、外貌做笑点；网络梗最多一次，除非人物设定就是这类人。

### 改法

- 把“好笑的事”改写成“当事人认真对待的事”。
- 越具体越好笑：“他很抠”不如“他把自助餐的薄荷糖装了一兜”。
- 删掉所有“笑了、哈哈、搞笑、逗”，删掉解释，把最好的一句放最后。

## 四、细致：让读者看见、听见、闻到

### 原则

细节不是形容词多，是名词、动作、数字准。

“她很伤心”不是细节；“她把外卖吃了一半，剩下的按原样盖好，放回袋子”是。

一段一个记忆点。好细节带信息：身份、关系、时间、钱、心情、危险。

### 情绪不要直写

表达层级从低到高：

**直接写情绪 < 心理活动 < 神态 < 动作 < 侧面反应**

- 低：“她很生气。”
- 中：“她脸色变了。”
- 高：“她把筷子放下，放得很轻。”
- 更高：“旁边的人都不说话了，服务员绕着她走。”

能写到动作和侧面反应，就别写“她很生气”。但也不是句句都要绕，关键处才用。

### 动态造型

- 用一个动词定住一个瞬间。听到消息，手一抖，针扎进指腹，她把手指放进嘴里吮了一下——比“震惊得说不出话”多十倍信息。
- 一个动作配一个物件：杯子、门把、衣角、手机、筷子、车票。
- 写“手在做什么”，比写“心里怎么想”可靠。

### 简笔与留白

- 能一笔勾出的，不写三笔。一个人护住碟子，伸开五指罩住，就写完了他的穷和怕。
- 留白：不写全，让读者补。别怕读者不懂，怕的是你替他们懂。

### 道具与反复

- 给人物一个道具，让它出现三次：第一次是日常，第二次是变化，第三次是代价。
- 例如一件外套：进门搭在椅背上，怕压皱；吵架时穿上又脱下；走的时候没拿。
- 反复不是重复，每次都要变；不变的那次是废笔。

### 详略与对比

- 紧张处细，旁听处简；主视角细，旁人简。
- 对比：同一人物前后的动作、眼神、称呼；不同人物对同一物的反应。
- 细节要回收。前面写的，后面要用；不回收的细节是闲笔，删。

### 五感

- 每场 2–3 种，不要五感全上。
- 气味和触感优先，因为它们更容易唤起记忆。
- 静也是一种声音：冰箱嗡嗡响，楼上拖椅子，谁都不先说话。
- 环境要参与动作：热得纸软、冷得手机掉电、吵得听错一个字、雨伞滴水弄湿裤脚。

### 反例

- 形容词三连：“美丽、温柔、善良”——空。
- 通感滥用：“她的声音像蓝色的丝绸”——读者要停下来解码。
- 风景明信片：整段写景，人物不动。
- 慢动作打斗：每个招式都解说，节奏死。
- 细节不承重：写了三百字早餐，却和人物、情节无关。

## 五、人物与对话

### 声音档案

给每个人一份声音档案（心里记，不输出）：句子长短、用词文雅还是粗、爱不爱反问、称呼对方什么、绝不说什么。

### 潜台词

台词是他说的，潜台词是他真正想要的、怕的、掩饰的。

- 写对话前，给每个角色写一句“他真正想说的”（不输出）。
- 四种落地：答非所问、转移话题、过度礼貌、用动作代替回答。
- 台词与潜台词要同一语调。不能上一句文绉绉，下一句网络梗。
- 别埋太深。读者接不到，等于没写；接得到但不点破，才是好。
- 对话后的动作要接住潜台词，不要解释。“你药吃了吗？”比“他其实很关心她”有效。

### 对话节拍

- 对话至少干一件事：推进剧情、暴露人物、施加压力。一件都不干的，删。
- 允许打断、抢话、答非所问、说半句。真实对话有废话，但小说里的废话要有用。
- 一个人一次不超过三句；长段发言要有动作或反应打断。
- 同时主导的不超过三个人，其他人用动作、短句或沉默参与；不要全员轮流转。
- 不是所有人都要风趣。一个冷面角色偶尔一句，比全员抖机灵更好。
- 称呼会变。关系一变，称呼先变；称呼不变，说明关系还没变。

### 双人还是多人

用户指定人数就照办；没指定，按场景功能选，默认用“能产生压力的最小人数”。

| 人数 | 适合 | 什么时候不要用 |
| --- | --- | --- |
| 2 | 私密、对峙、审讯、交易、告白、背叛、安慰 | 需要见证、裁判、盟友时，两个人撑不起场面 |
| 3 | 三角关系、引荐、挑拨、当众摊牌、需要见证 | 第三个人不改变力量平衡，只是旁听 |
| 4+ | 会议、宴席、庭审、战场、家族或群体冲突 | 只是想多几个人斗嘴；没有阵营和程序 |

- 加人必须带功能：施压、作证、打圆场、转移目标、结盟、背叛。没有功能的角色，站到背景里。
- 写到第四个人还在抢话，说明这场戏该拆成两场，或者改成“三个主导 + 一群反应”。

### 多人对话

多人戏不是“每个人轮流说一句”，是“谁有资格说、谁被打断、谁不说话”。

- 先定空间：谁坐、谁站、谁靠门、谁背窗。位置就是权力。
- 再定阵营：谁和谁一伙，谁中立，谁在观望。至少留一个“可能倒戈的人”。
- 一次只让一个问题在场。跑题要么有人拉回来，要么跑题本身就是策略。
- 发言权大致分配：主角 40%，对手 30%，第三方 20%，其余 10%。不要机械，但不能平均。
- 每轮结束，局面要变一点：联盟、信息、气势、位置。
- 允许打断、抢话、两个人同时说、替别人回答、低声侧聊。但一次只写清一条线，别让读者迷路。
- 多人场景里可读性优先：该用名字就用名字，必要时“名字 + 动作”，不要为了文雅写一堆“他说”。
- 沉默的人要有戏：他在做什么、看谁、什么时候开口。沉默者一开口，应该改变局面。
- 旁观者反应写 2–3 个就够，不要每个人都点头。
- 群体场面用“代表 + 合唱”：一个出头的人，两三个反应，不要给每个人起名。
- 结尾：最后一句话改变房间，或让一个人离席、沉默、做决定。

### 三种常用阵型

- **一对多**：围攻、审判、逼供。主角被轮流施压，只能抓一个突破口；多的人里要有一个“唱白脸”的。
- **二对二**：谈判、家族、帮派。关键不是谁有理，是谁先背叛；每句话都在试探盟友。
- **三角**：引荐、挑拨、告白、摊牌。第三个人是催化剂，不是裁判；他一开口，关系就变了。

### 自由间接引语

第三人称限知的高级写法：把人物的念头直接嵌进叙述，去掉“他想”“她觉得”。

- 直接引语：她想：“他不会再来了。”
- 间接引语：她想他不会再来了。
- 自由间接：他不会再来了。她把手机翻过来，屏幕朝下。

规则：

- 用人物会用的词，不用叙述者的书面语。
- 不加引号，不加“想”；让读者从上下文判断这是谁的念头。
- 一段里只跟一个人，别在两个人的意识之间跳。
- 关键处才用；全篇用会飘。

### 视角

限知视角不写视角人物不知道的事。“他不知道的是”是破功。

## 六、类型微调

| 类型 | 幽默 | 细节 | 注意 |
| --- | --- | --- | --- |
| 悬疑、惊悚 | 0–1，冷幽默 | 线索型细节 | 不拿受害者开玩笑；细节要能被记住并回收 |
| 言情 | 1–2，暧昧错位 | 身体距离、物件 | 不油；少写“邪魅一笑” |
| 科幻、奇幻 | 1–2，设定内幽默 | 规则的可感后果 | 不写说明书；用生活细节呈现世界观 |
| 武侠、古装 | 1–2，身份反差 | 器物、礼节、天气 | 不堆古语；对白可现代一点，叙述别翻译腔 |
| 都市、现实 | 2，职场冷幽默 | 价格、品牌、通勤 | 不玩过期网络梗 |
| 儿童、轻喜剧 | 2–3，动作喜剧 | 具体、干净 | 不写成人暗示 |

## 七、交付前自检（内部执行，不输出）

1. **中文生态**：有没有“作出、进行、造成、们、之一、有关、由于、成功地”？有没有抽象名词当主语？
2. **句长与音步**：有没有连续三句同样长？有没有超过 35 字没断的句子？读起来有没有“一、二、一”的绊脚？句尾是不是落在虚字上？
3. **场景**：这场戏的目标、冲突、变化是什么？删掉它，后文塌不塌？开场有没有一个非知道不可的问题？信息差给对了吗？
4. **反应链**：先刺激后反应？是不是只有心理，没有身体和动作？
5. **对话**：人数选对了吗？每段有潜台词吗？是不是有问必答、太合作？多人场景里读者能不能跟上谁在说话？沉默者有没有作用？
6. **视角**：自由间接引语有没有跳人？有没有写视角人物不知道的事？
7. **幽默**：笑点属于人物吗？解释了吗？密度过载了吗？危险场景降档了吗？
8. **细节**：一段一个记忆点吗？道具回收了吗？详略对吗？有没有形容词三连？
9. **一致性**：人名、称谓、视角、时间线、设定，全对了吗？
10. **水分**：删掉 10% 的字，信息有没有损失？有，说明还不够紧。

## 八、输出规范

- 默认只交正文。不交大纲，不交创作谈，不写“以下是”。
- 续写：直接接住上一段的动作、语气和信息，不重述前文，不换视角。
- 改稿时如果人数不对：先用一句话说明“这场更适合双人/三人”，再按新人数重写；删掉的角色，把他承担的功能转给在场的人，不要凭空消失。
- 改稿分三档，默认中档：
  - **轻**：只顺句、删虚词、换词，保留原声与结构。
  - **中**：调段落、场景、节奏，保留情节与人物关系。
  - **重**：重写场景与叙述顺序，保留设定与关键事实。
- 用户说“只润色”用轻档；说“重写”用重档；没说明用中档，并在开头一句话说明档位。
- 不要一次给三个版本，除非用户要比较。
- 正文里不要加小标题、编号、总结段。分段可以短，但别把小说写成 PPT。
- 要求冲突时，优先级：设定一致性 > 用户明确的风格要求 > 本 Skill 的默认值 > 平台惯例。
- 不替用户决定重大剧情（死亡、背叛、关系破裂）。写到那里停住，或按用户已给的方向写。

## 九、可调档位

- “再幽默点、太干了” → 幽默档 +1，增加错位对话和冷叙述，但不多加段子。
- “太贫了、收一收” → 幽默档 -1，删解释性笑点，只留人物自带的。
- “再细一点、要画面感” → 细节档 +1，加五感与动作分解，但一段只加一个记忆点。
- “太拖了、快点” → 细节档 -1，删环境与心理，保留动作和对话；场景挫折写狠一点。
- “像流水账” → 给每场加目标、阻力和变化；删掉没有“然后呢”的段落。
- “AI 味重” → 按第一节逐条替换，删总结句与排比，查句长分布。
- “翻译腔重” → 先改弱动词、被动句、抽象名词主语，再删“的”字链。
- “读着绊脚、不顺” → 查音步和句尾，删副词，长短句重新配。
- “对话假、像念台词” → 加潜台词，删解释，允许打断和答非所问。
- “只要双人” → 删到两个视角人物，第三个人改成电话/来信/不在场。
- “多人戏太乱” → 砍到三个主导发言人，其余用动作；明确空间和阵营。
- “多人像开会” → 给每个人一个私心，加打断、抢话、侧聊，删程序性发言。
- “视角飘” → 收紧限知，少用自由间接引语，一段只跟一个人。

## 十、一个对照示例

原文（AI 味 + 翻译腔）：

> 夜深了，城市的喧嚣渐渐褪去。林晚走进便利店，空气中弥漫着关东煮的香气，她的眼中闪过一丝复杂的情绪。仿佛时间在这一刻静止了。

改成：

> 凌晨一点，便利店只剩关东煮在咕嘟。林晚夹起一串萝卜，汤汁滴回格子里，像谁在打拍子。她抬头，看见收银台后面站着周野。三年没见，他胖了一点，围裙系得比当年的领带还认真。
>
> “好久不见。”她说。
>
> “关东煮第二串半价。”他说。

拆解（不输出给读者）：删掉天气套话、“眼中闪过”和“仿佛”；用关东煮的声音、汤汁做锚点；幽默来自错位对话和“围裙、领带”的反差；细节只留三个，都带信息（时间、人物关系、性格）；句子长短交替，没有一句超过 35 字。
