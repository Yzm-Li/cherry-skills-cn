# 去 AI 味与翻译腔速查

不是绝对禁词表，而是“出现就要有理由”。优先换成动作、物件、数字。

## 一、AI 味的五个来源

1. **安全词**：高频、中性、正确，缺方言、俚语、个人偏见。读起来像公文。
2. **句长均衡**：十句话八句在 15–25 字，缺短句的脆和长句的绵。
3. **模板结构**：“首先、其次、总之”“值得注意的是”当过渡；开头总起，结尾升华。
4. **空洞总结**：观点早说完了，还要复述一遍意义，画蛇添足。
5. **对话太合作**：有问必答，句句完整，没人打断、没人隐瞒、没人跑题。真实对话不是这样。

对症：每段给一个新信息；句长故意错开；删掉总结段；允许一个带毛边的具体判断。

## 二、中文西化病

| 病 | 例 | 改 |
| --- | --- | --- |
| 弱动词 + 抽象名词 | 作出贡献、进行研究、造成九十八人死亡 | 贡献很大、研究、死了九十八人 |
| 抽象名词作主语 | 他的收入的减少改变了他的生活方式 | 他收入减少，改了生活方式 |
| “们”泛滥 | 人们、观众们、听众们 | 人人、观众、听众 |
| “之一”蛇足 | 红楼梦是名著之一 | 红楼梦是名著 |
| “最……之一” | 他是最有名的人物之一 | 他很有名 |
| “有关、关于”冗余 | 关于他的申请，你看过了吗 | 他的申请你看过了吗 |
| “由于……使得” | 由于家境贫穷，使得他休学 | 他家境贫穷，只好休学 |
| “成功地”冗余 | 成功地推翻 | 推翻 |
| 被动滥用 | 他被选为议长、意见不被接受 | 他当选议长、大家不接受 |
| “的”字链 | 弯弯的杨柳的稀疏的倩影 | 弯弯的杨柳投下稀疏的倩影 |
| 前饰过长 | 一个长得像你兄弟、说话也像他的陌生男人 | 一个陌生男人，长得像你兄弟，说话也像他 |
| 副词“地” | 他苦口婆心地劝 | 他苦口婆心劝 |

## 三、高频词分级

**A 级：尽量清零**

> 仿佛、宛如、好似、不禁、忍不住、一丝、一抹、一缕、眼中闪过、嘴角勾起、空气凝固、时间静止、五味杂陈、难以言喻、说不清道不明、命运的齿轮、无声地诉说、在这一刻、不仅仅是……更是……、这就是……的力量。

**B 级：一段不超过一次**

> 缓缓、轻轻、微微、淡淡、默默、深深、静静、悄悄、突然、瞬间、顿时、心里一紧、心头一暖、鼻子一酸、眼眶一红、仿佛整个世界。

**C 级：结构信号**

> 随着……、当……的时候、在……的背景下、对于……而言、关于……、进行……、使得……、被……所……、与此同时、然而、值得一提的是、总的来说、更重要的是。

## 四、十组替换

1. 她很紧张 → 她把杯垫撕成两半，又对齐，又撕。
2. 他很生气 → 他把筷子放下，放得很轻。
3. 房间很乱 → 外卖盒摞到第三个，最上面那个还插着筷子。
4. 天气很冷 → 他说话有白气。手机在兜里震了一下，他没掏。
5. 时间过得很快 → 她抬头，窗外那栋楼的灯已经灭了一半。
6. 他很有钱 → 他点烟用火柴，火柴盒是酒店顺的。
7. 她哭了 → 她低头找纸巾，包底只有一张小票。
8. 气氛尴尬 → 两个人同时去拿菜单，又同时缩手。
9. 他很累 → 他坐在玄关换鞋，换到一半，头靠在鞋柜上。
10. 他很好看 → 他笑的时候先皱一下鼻子，像没睡醒。

## 五、句式病

| 病 | 例 | 改法 |
| --- | --- | --- |
| 长定语 | 那个穿着黑色风衣、手里提着旧皮箱、眼神疲惫的男人 | 拆三句 |
| 排比升华 | 是告别，是成长，是命运 | 只留一句最具体的 |
| 总结句 | 这一刻，她终于明白，有些路只能一个人走 | 删，停在动作上 |
| 解释情绪 | 他这样说，是因为他其实很在乎她 | 删“因为”后半句 |
| 万能比喻 | 像一朵花、像一场梦 | 换成人物经验里的喻体 |
| 翻译腔 | 一个想法浮现在他的脑海中 | 他想到 |
| 形容词三连 | 美丽、温柔、善良 | 选一个，用动作证明 |

## 六、三遍扫描

1. **搜词**：仿佛、不禁、一丝、眼中、嘴角、空气、时间、心中、命运。
2. **数句长**：连续三句同长，改一句；十句里大半在 15–25 字，重写一段。
3. **搜段**：每段最后一句是不是总结？连续两段是否同一功能？

## 七、例外

人物是翻译、播音、公文写作从业者，或叙述者本身在模仿某种腔调时，这些词可以有意识地用，但要让读者看出是“他在这么说”，不是“作者只会这么写”。
