# 三遍改稿清单

## 第零遍：先诊断

| 症状 | 先改哪里 |
| --- | --- |
| 卡 | 句法、翻译腔、连接词 |
| 平 | 场景目标、冲突、变化 |
| 假 | 细节不承重、情绪直给 |
| 油 | 笑点解释、密度过载 |
| 空 | 总结升华、没有信息增量 |

## 第一遍：流畅

- [ ] 朗读一遍，标出换气困难的地方。
- [ ] 拆掉 35 字以上、没有标点的长句。
- [ ] 数十个句子的长度。大半都在 15–25 字，重写一段；连续三句同长，改一句。
- [ ] 读出声，听音步。有没有“一、二、一”的跛脚？句尾是不是落在“的、了、着”上？
- [ ] 删掉“慢慢地、轻轻地、非常地”这类副词，动作会更稳。
- [ ] 删掉可删的连接词：因为、所以、虽然、但是、然而、于是。
- [ ] 找“作出、进行、造成、们、之一、有关、关于、由于、成功地”，逐个改。
- [ ] 找抽象名词当主语的句子，改成人或事作主语。
- [ ] 找被动句，能主动就主动。
- [ ] 找“的”字链和过长的前饰定语，拆成后饰短句。
- [ ] 一段只做一件事；功能重复的段落合并。
- [ ] 删掉每段最后一句的总结、升华、抒情。
- [ ] 第一段是否从具体锚点开始。

## 第二遍：场景与节奏

- [ ] 每场戏写清：目标、冲突、挫折、离场变化。
- [ ] 第一段有没有一个非知道不可的问题？开场是不是天气或背景？
- [ ] 删掉这场戏，后文塌不塌？不塌就合并或删。
- [ ] 反应链是否先刺激后反应？是否只有心理，没有身体和动作？
- [ ] 反应是不是四个全上？砍到一两个。
- [ ] 镜头是否在一段里反复拉远拉近？
- [ ] 转场是否靠“与此同时”？换成物件、声音、动作。
- [ ] 有没有不推进、不塑造、不营造氛围的水段？
- [ ] 删掉 10% 的字，信息有没有损失？

## 第三遍：幽默与细节

- [ ] 每段对话有没有潜台词？是不是有问必答、太合作？
- [ ] 每个人说话像一个模子吗？遮住名字认不认得出？
- [ ] 人数是不是“能产生压力的最小人数”？第三/第四个人改变了什么？
- [ ] 多人戏有空间、阵营、议程吗？同时主导发言的超过三个了吗？
- [ ] 沉默的人有作用吗？最后一句改变了房间吗？
- [ ] 自由间接引语有没有跳人？视角有没有写到人物不知道的事？
- [ ] 找到所有想让人笑的地方，标出来。
- [ ] 每个笑点问一句：这是这个人会说的话吗？
- [ ] 删掉笑点之后的解释句、捧场词。
- [ ] 数一数密度：是不是每段都在抖机灵？
- [ ] 危机、悲伤场景是否降档？代价是否真实？
- [ ] 有没有拿弱者、疾病、地域、性别、外貌开玩笑？
- [ ] 每段是否有一个记忆点？
- [ ] 五感是否超过三种？删到三种以内。
- [ ] 有没有形容词三连、万能比喻、风景明信片？
- [ ] 道具出现了几次？每次变了吗？回收了吗？
- [ ] 细节是否带信息：身份、关系、时间、钱、危险。
- [ ] 紧张处是否足够短、稀？舒缓处是否敢展开？

## 评分表

每项 1–5 分，低于 3 分重写对应段落。

| 项目 | 1 分 | 3 分 | 5 分 |
| --- | --- | --- | --- |
| 流畅 | 拗口、要回读 | 能读，偶有卡顿 | 一口气读完 |
| 中文生态 | 翻译腔明显 | 偶有西化句 | 像中文，不像译文 |
| 场景 | 没有变化 | 有变化但可预测 | 每场都逼出下一步 |
| 对话/群像 | 轮流发言、认不清谁在说 | 能跟上，但有人是工具 | 人数最少、阵营清楚、沉默者有用 |
| 幽默 | 尴尬、解释笑点 | 有一两处轻笑 | 笑点长在人物身上 |
| 细节 | 形容词堆砌 | 有画面但可替换 | 只有这个场景才有 |
| 人物声音 | 谁说话都一样 | 主角有辨识度 | 遮住名字也认得出 |
| 一致性 | 设定冲突 | 小瑕疵 | 人名、时间线、视角全对 |

## 常见病与处方

| 病 | 处方 |
| --- | --- |
| 流水账 | 给每场戏一个目标、一个阻力、一个变化 |
| 节奏拖 | 删环境与心理，只留动作和对话；挫折写狠 |
| 人物扁 | 给他一个自相矛盾的地方 |
| 对话假 | 让一个人答非所问，让一个人说半句 |
| 结尾空 | 停在动作、画面或没说完的话上 |
| 翻译腔 | 先改弱动词、被动、抽象名词主语，再删“的”字链 |
| AI 味重 | 按《去 AI 味与翻译腔速查》逐条替换，查句长分布 |
| 笑点油 | 删解释、删捧场词、降密度 |
| 细节假 | 换成只有这个人物、这个地方才有的动作和物件 |
