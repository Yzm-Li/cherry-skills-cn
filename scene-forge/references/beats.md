# 场景节拍模板

## 一、标准八拍

| 节拍 | 作用 | 大约篇幅 |
| --- | --- | --- |
| 1 进入 | 人物带着具体目标/状态进场 | 10% |
| 2 触发 | 一件事打破平衡，问题出现 | 10% |
| 3 第一次尝试 | 失败/部分成功，暴露阻力 | 20% |
| 4 升级 | 代价、时间、对手反应加码 | 15% |
| 5 转折 | 新信息/背叛/反制，局面翻转 | 15% |
| 6 危机选择 | 两个都痛的选项，必须选一个 | 10% |
| 7 代价 | 选择后的损失，具体到人/物/路 | 10% |
| 8 离场 | 新问题/新决定/新威胁 | 10% |

不是每场都要八拍。短场景可以只有 1、2、5、6、8。

## 二、六拍短场景

1. 进入 + 目标
2. 触发 + 阻力
3. 尝试 + 失败
4. 转折
5. 选择 + 代价
6. 离场钩子

适合单元剧、过渡场、对话为主的戏。

## 三、动作场景五拍

1. 目标 + 倒计时
2. 第一个障碍
3. 升级（体力/空间/敌人）
4. 转折（计划失效/盟友倒下）
5. 选择 + 代价 + 离场

动作场景不要每个招式都解说；用空间、声音、身体反应。

## 四、安静场景四拍

1. 两个人/一个人进入一个必须面对的空间
2. 表面话题（潜台词）
3. 一句越界的话/一个动作，打破平衡
4. 选择：说破/不说破/离开

安静场景的冲突在潜台词、停顿、动作，不在音量。

## 五、群像场景五拍

1. 空间 + 阵营（谁和谁一伙）
2. 议程（必须解决什么）
3. 第一次交锋（谁先开口，谁被打断）
4. 阵营变化（倒戈/中立/离席）
5. 决定/未决 + 离场

同时主导不超过三个人；沉默者最后开口。

## 六、揭露场景五拍

1. 试探
2. 否认
3. 证据
4. 反指控/新秘密
5. 关系变化 + 新问题

揭露前要有伏笔；揭露后要有人付代价。

## 七、伏笔与回收

每个场景至少做一件事：

- 种一个后面要用的物件/信息。
- 回收一个前面种下的物件/信息。
- 或者两者都做。

检查：

- 这个细节后面用了吗？
- 这个转折前面有影子吗？
- 这场结束时，读者多知道了什么？

## 八、节拍不是公式

- 节拍是检查表，不是填写表。
- 如果场景在第三拍就达到高潮，不要硬拖到第八拍。
- 如果场景不需要转折，就不要为转反转。
- 最好的节拍，是读者感觉不到节拍。
