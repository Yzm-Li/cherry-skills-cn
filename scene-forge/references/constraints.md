# 场景条件清单

## 一、硬条件

不满足就淘汰候选，不要打分了再“想办法圆”。

### Canon

- 世界规则允不允许这件事？
- 能力上限、代价、冷却是什么？
- 已发生的事件有没有冲突？
- 人物关系到了哪一步？
- 有没有必须保留的原作事实？

### 人物

- 他想要什么？现在就要吗？
- 他怕什么？底线是什么？
- 他知道什么？不知道什么？
- 他的能力/资源够吗？
- 他会误判什么？

### 时间

- 这场发生在什么时候？
- 上一场结束后，他来得及赶到吗？
- 伤/损失恢复了吗？
- 倒计时还剩多久？
- 信息传到该听的人耳朵里了吗？

### 空间

- 在哪？室内/室外？出口在哪？
- 谁能看到、听到？
- 有什么道具可用？
- 空间本身能不能制造压力（窄、高、吵、冷、黑）？

### 视角

- 这场跟谁的眼睛？
- 他不知道什么？
- 有没有写到他不可能知道的事？

### 剧情

- 这场必须完成什么任务？
- 后面哪一场依赖它？
- 删掉这场，后文会塌吗？

### 分级

- 暴力/亲密/敏感内容的边界在哪？
- 需要留白还是直写？

## 二、软条件

### 类型

- 悬疑：信息差、线索、误导。
- 言情：关系变化、身体距离、潜台词。
- 武侠：规矩、门派、面子、动手的理由。
- 科幻：规则的可感后果。
- 都市：钱、房、工作、通勤。
- 喜剧：错位、反差、节奏。

### 基调

- 冷/热/荒诞/克制/悲/喜。
- 这场之后，读者应该更紧张、更心疼、更好奇，还是更轻松？

### 节奏位置

- 开场：建立问题。
- 上升：加码、误会、逼近。
- 中点：反转、真相、不可逆。
- 低谷：失去、失败、孤立。
- 终局：决战、选择、代价。

同一场戏放在不同位置，最优方案不同。

### 读者

- 想让读者知道什么？
- 想让读者担心谁？
- 想让读者猜什么？
- 想让读者等什么？

### 主题

- 这场在问什么？
- 人物的选择，支持还是反驳主题？
- 结尾有没有把这个问句推进一步？

### 预算

- 能写多长？
- 几个角色在场？
- 几个场景/道具？
- 需不需要大场面？

## 三、条件矩阵模板

```markdown
| 条件 | 内容 | 类型 |
| --- | --- | --- |
| 必须完成 | 拿到钥匙 | 硬 |
| 时间 | 晚宴 20 分钟 | 硬 |
| 地点 | 宴会厅 + 楼上 | 硬 |
| 视角 | 林晚，限知 | 硬 |
| 对手 | 周野，多疑 | 硬 |
| 不能暴露 | 林晚身份 | 硬 |
| 情绪 | 紧张 + 一点黑色幽默 | 软 |
| 篇幅 | 1200 字 | 软 |
| 主题 | 救一个人要不要出卖自己 | 软 |
```

## 四、条件冲突时

- 硬条件互相冲突：先保 canon 和人物，改场景，不要改设定。
- 剧情任务和人物动机冲突：给人物一个“不得不”的理由，不要让他 OOC。
- 时间和空间冲突：换地点、加时间压力、删掉不必要的人物。
- 用户要求和 canon 冲突：明确说“这会变成 AU”，不要偷偷改。

## 五、默认假设

用户没给的条件，用默认值，并在输出开头一句话说明：

```text
默认假设：第三人称限知；林晚不知道钥匙在书房；晚宴还有 20 分钟。
```

最多两条。假设太多，说明该问。

## 六、十个问题

1. 这场戏的任务是什么？
2. 谁想要什么？
3. 谁/什么挡着？
4. 失败会失去什么？
5. 为什么是现在？
6. 为什么是这个地方？
7. 谁在场会让它更痛？
8. 谁知道什么、不知道什么？
9. 这场结束后，什么变了？
10. 删掉这场，后文会塌吗？
