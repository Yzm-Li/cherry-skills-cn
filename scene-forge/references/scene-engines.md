# 场景引擎手册

## 一、怎么选引擎

先问：这场戏的**核心动作**是什么？

| 核心动作 | 引擎 |
| --- | --- |
| 抢东西 | 争夺 |
| 逼问信息 | 审讯 |
| 交换条件 | 谈判 |
| 救人/脱困 | 救援、围困 |
| 揭秘密 | 揭露 |
| 测试忠诚 | 背叛 |
| 在众人面前表演 | 仪式、表演、审判 |
| 追/逃 | 追逃 |
| 告别/重逢 | 情感场 |

不要连续三场用同一个引擎。读者会疲劳。

## 二、十二种引擎

### 1. 争夺

**核心**：一个具体东西，双方都想要，且只能一个人拿到。

**需要**：稀缺性、合法性争议、时间限制、失败代价。

**节拍**：发现目标 → 第一次接触 → 对手加码 → 规则/空间限制 → 抢夺/交换 → 代价 → 归属未定。

**崩法**：东西太容易拿；对手不出现；抢完没有后果。

### 2. 审讯

**核心**：一方要从另一方嘴里拿到信息，双方权力不对等。

**需要**：信息差、筹码、时间压力、说谎的动机。

**节拍**：提问 → 回避 → 施压 → 反将一军 → 信息半真半假 → 谁信了谁。

**崩法**：一问就招；靠暴力代替博弈；信息倾倒。

### 3. 谈判

**核心**：双方各有一个对方想要的东西，交换，但都不想吃亏。

**需要**：双方都有 BATNA（谈崩了也能活的方案）、可信威胁、隐藏底牌。

**节拍**：开价 → 拒绝 → 加码 → 揭底牌 → 谈崩边缘 → 成交/掀桌 → 谁亏了。

**崩法**：一方无脑让步；没有替代方案；靠嘴炮解决。

### 4. 救援

**核心**：在时间/空间压力下把人/东西救出来。

**需要**：倒计时、障碍、失败代价、不能硬闯的理由。

**节拍**：发现 → 计划 → 第一次失败 → 时间缩短 → 换方案 → 救人/失败 → 代价。

**崩法**：主角太强；障碍是摆设；救完没有损失。

### 5. 揭露

**核心**：一个秘密被揭开，关系/局面重排。

**需要**：前文伏笔、知情者、否认/证据、揭露后的代价。

**节拍**：试探 → 否认 → 证据 → 反指控 → 承认/崩溃 → 关系变化 → 新问题。

**崩法**：秘密没有伏笔；揭露后没人受影响；一次说完。

### 6. 背叛

**核心**：忠诚被测试，盟友在压力下倒戈。

**需要**：双重忠诚、利益/恐惧、倒戈的代价、被背叛者的盲点。

**节拍**：暗示 → 试探 → 加码 → 关键时刻缺席/反水 → 后果 → 谁还信谁。

**崩法**：没有动机；为反转而反转；背叛者没有代价。

### 7. 仪式

**核心**：一套社会规则逼人在众人面前表演。

**需要**：观众、规矩、越界的代价、私下的真实目的。

**节拍**：入场 → 规矩 → 小越界 → 被警告 → 大越界/被将一军 → 仪式继续/中断 → 谁丢了脸。

**崩法**：仪式只是背景；没有观众压力；规矩随便破。

### 8. 围困

**核心**：出不去，压力在封闭空间里累积。

**需要**：封闭空间、倒计时、内部矛盾、资源减少。

**节拍**：进入 → 发现出不去 → 第一次冲突 → 资源/信任减少 → 内部倒戈 → 突围/被困 → 代价。

**崩法**：空间不封闭；压力不升级；重复吵架。

### 9. 追逃

**核心**：一方追，一方逃，地理和体力决定胜负。

**需要**：清楚的空间地图、障碍、体力/资源消耗、追者的动机。

**节拍**：发现 → 起跑 → 第一次甩开 → 障碍 → 被追上 → 换路线/反击 → 逃脱/被抓。

**崩法**：没有地图；追兵瞬移；逃的人不费力。

### 10. 表演/比赛

**核心**：在公开场合展示能力，输赢有观众和后果。

**需要**：规则、评委/观众、对手、失误代价、隐藏实力。

**节拍**：准备 → 上场 → 失误 → 追赶 → 对手出招 → 绝杀/失败 → 舆论后果。

**崩法**：蒙太奇带过；没有规则；主角开挂。

### 11. 审判

**核心**：一套程序决定一个人/一件事的对错。

**需要**：规则、证据、双方陈述、旁听反应、程序漏洞。

**节拍**：开庭 → 指控 → 辩护 → 证据战 → 程序越界 → 裁决 → 后果。

**崩法**：靠一段演讲翻盘；程序不存在；旁听只是背景。

### 12. 告别/重逢

**核心**：两个人带着未说出口的历史，在一个无法回避的时刻见面/分开。

**需要**：旧关系、未说出口的话、时间压力、不能回头的选择。

**节拍**：相遇 → 寒暄/错位 → 旧事被提起 → 试探 → 必须说真话的时刻 → 选择 → 离开/留下。

**崩法**：靠回忆煽情；对话解释一切；没有代价。

## 三、引擎组合

- **主引擎 + 一个转折**：例如谈判为主，揭露为转折。
- **不要超过两个引擎**：争夺 + 救援 + 审判，会散。
- 连续场景换引擎：上一场审讯，下一场救援，再下一场仪式。
- 文戏也需要引擎：谈判、揭露、告别都是引擎，不是“没动作”。

## 四、快速选择

```text
这场戏必须发生什么？
谁阻止它？
失败会失去什么？
在什么地方/时间发生最痛？
谁在场能让它更痛？
→ 选能同时满足这五条的引擎。
```
